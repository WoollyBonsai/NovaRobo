# 🚀 About Nova-Robo

Nova-Robo is a **student-led hardware innovation startup** focused on building real-world engineering solutions across **robotics, rocketry, electronics, embedded systems, and aerospace technology**.

We believe innovation begins with curiosity and becomes meaningful through hands-on engineering. Every project we build is designed to solve real problems while pushing the boundaries of learning, experimentation, and technology.

From the initial concept to the final prototype, our mission is simple:

> **Build. Innovate. Explore.**
